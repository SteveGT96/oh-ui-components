# DateField

#### Displays a styled Date field component.

<Canvas of={DateFieldStories.Default} />

## Usage

```typescript
import { DateField } from "@/lib/components/ui/DateField";
```

```typescript
<DateField
    label="DateField"
    onChange={(value) => {}}
    fieldValue={new Date()}
/>
```

## Props

```typescript
interface DateFieldProps {
  label: string;
  fieldValue: Date | undefined;
  className?: string;
  onChange: (value: Date | null) => void;
  disabled?: boolean;
  error?: boolean;
  helperText?: string;
  required?: boolean;
}
```
