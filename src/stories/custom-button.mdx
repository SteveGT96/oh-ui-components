# Button

#### Displays a styled Button component.

<Canvas of={CustomButtonStories.Default} />

## Usage

```typescript
import { CustomButton } from "@/lib/components/ui/custom-button";
```

```typescript
<CustomButton
    title="Button"
    onClick={() => {}}
/>
```

## Props

```typescript
interface CustomButtonProps {
  variant?:
    | "default"
    | "destructive"
    | "outline"
    | "secondary"
    | "ghost"
    | "link";
  title: string;
  onClick?: () => void;
  disabled?: boolean;
  icon?: LucideIcon;
}
```
